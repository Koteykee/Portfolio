# This project is a personal portfolio website designed to showcase my background, skills and development experience.
It serves as a central hub where visitors can learn more about me, explore my projects and easily get in touch.

While working on this project, I learned and successfully implemented the following:

1. Creation of a structured and visually appealing personal profile page with information about my background, skills and tech stack.
2. Development of a projects section highlighting my pet projects with descriptions, tech stack and preview image.
3. Implementation of responsive design to ensure a smooth experience across different screen sizes.
4. Integration of navigation to provide clear and intuitive user flow.
5. Adding contact links and communication options to make networking and collaboration easy.
6. Focus on clean UI/UX design principles to present information in a concise and engaging way.
